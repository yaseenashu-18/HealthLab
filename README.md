## About HealthLab AI

**HealthLab AI** is a modern, minimalist healthcare web application designed to simplify diagnostic bookings, report management, and personalized AI health consultations. Built with an Apple-inspired clean UI and a minimal color scheme, HealthLab AI provides seamless access to essential health services for users, doctors, lab technicians, and pharmacies.

---

## Key Features

- 🔬 **Book Diagnostic Tests**: Easy booking for lab tests and full-body health packages with doorstep sample collection.
- 📁 **Centralized Health Reports**: View, download, and organize diagnostic lab reports and X-ray scans in one secure place.
- 🤖 **Smart Health AI Assistant**: 24/7 AI-powered health consultations, symptom analysis, and instant lab report explanations.
- 🩺 **Role-Based Access**: Specialized views and dashboards for Users, Doctors, Lab Technicians, and Pharmacies.
